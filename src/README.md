# PLKAB Fönsterinventering

Detta är en Vite/React-prototyp för fönsterinventering.

## Kör lokalt

```bash
npm install
npm run dev
```

## Deploy till Vercel

1. Ladda upp innehållet i denna mapp till ett GitHub-repo.
2. Gå till Vercel och välj Add New Project.
3. Välj GitHub-repot och klicka Deploy.

## Viktigt

- Data sparas lokalt i webbläsaren/iPaden.
- Exportera alltid CSV eller PDF efter platsbesök.
- PDF-knappen öppnar en utskriftsvänlig rapportsida. Välj Skriv ut/Spara som PDF.

## Ändringar i denna version

- PDF-knappen fungerar via utskrift/spara som PDF.
- Loggan visas högst upp i appen och i rapporten.
- ID är tomt och fylls i manuellt.
- Fönstertyp går från F1 till F30.
- Skick: OK, Mindre bra, Acceptabelt, Mycket dåligt.
- Fönstertyp visar vald littera plus fri text.
