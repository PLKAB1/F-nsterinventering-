# PLKAB Fönsterinventering

## Kör lokalt
npm install
npm run dev

## Publicera på Vercel
1. Skapa ett nytt GitHub-repo.
2. Ladda upp alla filer i denna mapp.
3. Gå till Vercel > Add New Project.
4. Välj GitHub-repot.
5. Framework preset: Vite.
6. Build command: npm run build.
7. Output directory: dist.
8. Deploy.

## iPad
Öppna Vercel-länken i Safari > Dela > Lägg till på hemskärmen.

Data sparas lokalt i iPadens webbläsare. Exportera CSV/PDF efter varje inventering.
